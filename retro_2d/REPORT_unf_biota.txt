REPORT: Biota track, unfiltered vs 5 cm-filtered DJI Terra export
2026-11-01. Script retro_2d\unf_test.py. Outputs retro_2d\outputs\unf_test\.

QUESTION
Does the DJI Terra 5 cm spatial filter change the LiDAR cover, height or classes enough
to re-export the other Dampier 2026 sites without it?

RECOMMENDATION
Re-export Bunda Extra first, as a second test, and keep the OLD georeference.
- Heights do not change. Cover drops by 0.020 (median) in 98.7 % of cells.
- At Biota only 1.5 % of k4r cells (0.9 % k3r) change class, because Biota is
  92 % class 4. The cells that change are mostly "mid, dense" (k4r C3): 15 % of them.
- Sites with more C3 cells will change more. Estimate from the Biota per-class rates:
  Bunda Extra ~8 %, Country Downs ~4 %, South Dampier ~2 %, 9 Mile <1 %.
  This estimate is weak: the filter effect can be different at each site.
- If Bunda Extra changes <= 3 % of its cells, stop: use the existing clouds with the
  caveat. If it changes more, re-export Country Downs and South Dampier too.
- The cover drop is systematic. It is about 60 % of the Dampier - Yawuru median
  cover difference (0.034), so pooled Dampier + Yawuru labels carry a small bias
  until the re-export is done.

GEOREFERENCE (separate finding)

  The header extents also differ by -1.0 / -1.5 m.
User ruling: the old (filtered) position is correct.
