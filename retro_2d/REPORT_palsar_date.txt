REPORT - PALSAR-2 acquisition dates 2019-2025 vs brightness and k3r / k4r class shares
====================================================================================

Status: complete, 2026-10-31. User request: use the PALSAR date rasters (mosaic + clip)
and see if the dates match anything in scene brightness or the class results.
Maps: k3r / k4r, own model per year (the standard result). Follows REPORT_palsar_shift.txt.


ANSWER
------

1. The date rasters are in every year's folder (JAXA <tile>_date_F02DAR.tif, days since
   2014-05-24). Each annual mosaic is 4-7 acquisitions (strips) over the mainland, from
   different months, beams and incidence angles. 2023 is mostly wet-season data
   (Dec 2022 - Mar 2023).

2. WITHIN a year, the class map steps at strip boundaries. Near each boundary (2 km each
   side; the same pixels in the other 4 years remove the land difference):
   - median step 0.10 SD (HV) to 0.21 SD (alpha); mean class code 0.10 (k3r), 0.15 (k4r).
   - the largest steps: 0.3-0.5 classes, "no canopy" share 15-29 points.
   - the step follows the rain difference between the two dates: wetter date ->
     brighter, higher alpha, taller classes. 20 seams: k3r code rho +0.65 (p 0.002),
     k4r +0.66 (p 0.001), HV +0.54, alpha +0.57. Sign agrees in 6-7 of the 8 seams
     with |rain difference| >= 30 mm.
   - incidence angle difference: weak (code rho +0.19 / +0.28, n.s.). Days apart: none.
   - CORRECTION (2026-10-31, follow-up test): the rain link rests mostly on the 3 seams of
     2024-11-25, where rain (+38-47 mm) and incidence (+10-12 deg, W2 beam) change
     together. Without them: code rho +0.42 / +0.45 (p 0.09 / 0.07, n = 17). Seams with
     the same incidence only: code rho +0.11 / +0.23 (n.s., n = 13). Partial on linci
     (all 20): +0.63 / +0.65. Steps also occur with no rain difference where path or
     incidence changes (2024-01-12 | 01-03: HV +0.71; 2021-12-08 | 10-22: alpha +0.37).
     So moisture is plausible, but these data cannot say it is the main cause. Rain30 is a
     weak moisture proxy (monthly, mainland mean), which biases this test towards null.
   - The F02DAR XML records RTC (slope correction to gamma0) only; no strip
     normalisation. Raw seam steps remain (median 0.15 SD HV).
   - The decomposition inputs are HH_s / HV_s = gamma0 / cos(linci), which adds an
     incidence factor back into Pd / Ps / Pu (alpha is a ratio: not affected).

3. The label cells sit on only 2-3 strips per year. These strips have NO label cells:
   2019 2019-08-07 (33 %), 2021 2021-12-08 (33 %), 2023 2023-12-06 (32 %),
   2024 2024-01-03 + 07-31 (39 %). 2025: every large strip has label cells.
   So 30-40 % of the mainland in 2019-2024 is predicted from acquisitions that the
   model did not train on.

4. The 2023 lead (label cells brighter than the mainland, REPORT_palsar_shift) comes from
   WHERE the strips lie (land + label coverage), not from an acquisition step:
   - On the SAME date, label cells are brighter than the mainland in every year
     (HV +0.08 to +1.38 SD). 2023 (+0.87 / +0.40) is not unusual. They are woodier sites.
   - 2023 label cells are on two WET dates (2022-12-21, rain30 84 mm; 2023-03-29, 54 mm).
     32 % of the mainland is the dry 2023-12-06 W2 strip (10 mm), with no label cells,
     darker (HV -10.71 vs -9.74 dB) and with low classes (no canopy 27 %, C1 51 %).
   - At its boundary with 2022-12-21 the net step is small (HV +0.05, code +0.02), so
     most of that strip's low classes is its land, not the acquisition. The low-class
     excess of 2023 therefore comes from where that strip lies, not from a seam jump.

5. ACROSS years (n = 5), the date features do not explain the class shares.
   wet_pct (calendar Nov-Apr share) vs k3r no canopy rho +1.0 (p 0.02) is 1 hit in
   54 tests and wet_pct is a poor wetness measure (Nov-Dec dates had 3-10 mm).
   Rain30 is not known for 2025 (ERA5 file ends 2025-07), so no year test with it.

6. 2019 decomposition anomaly (alpha ~70 deg, Surface ~-17 dB): it is in ALL 2019
   strips (Feb, Aug, Oct, Nov; three beams), so it is not one acquisition date. High
   alpha also occurs in single strips in other years (2021-06-09, 2023-03-29, 2024-11-25)
   but there the seam test shows it is mostly land. Cause still open.

Summary: dates matter inside each mosaic. A wet strip next to a dry strip gives brighter
PALSAR and taller classes at the boundary (up to 0.5 class). Many strips have no label
cells. This is a within-year artefact in the k3r / k4r maps, in addition to the year
signature. It does not explain the scene-level class shares between years.

METHOD
------

Script     retro_2d\palsar_date.py (log palsar_date.log; first run palsar_date_run1.log,
           same numbers except the rain tests, which were NaN there)
Dates      <tile>_<yy>_date_F02DAR.tif, uint16 days since 2014-05-24; 0 / 1 = no data.
           Sampled by nearest at the mainland pixel centres of the 2021 grid (= mosaic +
           clip). linci from each year's linci.tif. Beam / path / incidence from the tile
           XMLs (2021 folder has no XMLs).
Ground     palsar_shift fixed ground, also with a date in all 5 years: 35,097,381 px.
           PALSAR values and class codes from outputs\palsar_shift\cache.
Rain30     ERA5 monthly mainland mean, pro rata over the 30 days before the date.
Seams      For each pair of strips >= 0.5 % of fixed ground: pixels of strip a within
           2 km of strip b, and the reverse; >= 2000 px per side. Step = median a - median
           b, in pooled within-year SD (class code: mean difference). Placebo = median of
           the same step at the same pixels in the other 4 years. Net = step - placebo.


CAVEATS
-------

1. Seams are not independent: some strips are in 2-3 seams (2024-11-25 in 3). The
   p values are optimistic. The 8-seam sign count is the more robust result.
2. Rain30 is one mainland mean per date, not per strip, and monthly pro rata. A local
   storm on one strip is not seen. 2025 Aug-Dec rain is missing (ERA5 file ends 2025-07).
3. The 2024-11-25 strip is also a W2 beam with +10-12 deg incidence; rain and incidence
   are confounded in its 3 seams.
4. The placebo assumes the land difference across a seam is stable over the 5 years.
   Real change (fire) near a seam adds noise.
5. The seam band is 2 km wide; it tests the boundary only, not the whole strip.
6. n = 5 for the cross-year tests; read rho sizes only.
7. CALIBRATION (found 2026-10-31, not acted on): the F02DAR XML gives DN as linear
   amplitude, gamma0 dB = 10*log10(DN^2) - 83. PALSAR_process_linux.py uses
   gamma0 = DN / 10000 (as power). Monotonic, so per-year trees on HH / HV are not
   affected, but the dB values here are not true gamma0 (HH about -15 dB true vs -6 here),
   and the decomposition (Pd / Ps / Pu, alpha) is computed from amplitude, not intensity.
   Also sigma0 = gamma0 * cos(theta), not gamma0 / cos(theta).
